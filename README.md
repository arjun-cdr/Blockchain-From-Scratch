# Blockchain-From-Scratch-Python
<h4>A modular, decentralized blockchain built from first principles in Python. This repository traces the progression from basic data structures to core cryptographic validation, Proof-of-Work (PoW) consensus, decentralized P2P synchronization, and Web3 smart contract integration. </h4>

<h3>Technical Features Overview</h3>
<p>1. Transaction Ledger Management : State handling and execution of transaction schemas using native data structures.</p>
<p>2. Object-Oriented Block Architecture: Encapsulated block representations tracking metadata, timestamps, nonces, and parent hashes.</p>
<p>3. Deterministic SHA-256 Hasher: Canonical JSON serialization ensuring consistent block hashes across heterogeneous environments.</p>
<p>4. Tamper Detection & Integrity Engine: Recursive parent-child hash verification to detect historical ledger modifications.</p>
