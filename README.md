# Blockchain-From-Scratch-Python
<h3>A modular, decentralized blockchain built from first principles in Python. This repository traces the progression from basic data structures to core cryptographic validation, Proof-of-Work (PoW) consensus, decentralized P2P synchronization, and Web3 smart contract integration. </h3>
<h4> Step 1 : Transaction Ledger - Implements a basic transaction ledger where a new transaction is validated if and only if it matches validation criteria.</h4>
<h4> Step 2 : OOP Block Class - Implements a block class that serves as a template where every blockin the blockchain is an object of that class.</h4>
<h4> Step 3 : Secure Hashing Using SHA256 - Implements an advanced cryptographic algorithm (SHA256) to calculate block hash.</h4>
